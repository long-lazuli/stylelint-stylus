WHAT THE AGENT DOES:
--------------------

For EVERY issue, the agent:

  1. Reads Documentation
     - Issue file from issues/modernization/
     - Stylus documentation references
     - Technical docs (Vitest, TypeScript, etc.)

  2. Plans Tests
     - Designs test structure
     - Identifies edge cases
     - Sets coverage targets

  3. Writes/Updates Tests (TDD RED)
     - Creates test files
     - References Stylus docs
     - Verifies tests fail appropriately

  4. Implements Changes (TDD GREEN)
     - Follows issue specification
     - Makes tests pass
     - Validates against Stylus spec

  5. Verifies & Refines
     - Runs full test suite
     - Checks coverage ≥80%
     - Tests with real Stylus files
     - Validates compliance

  6. Updates Issue Status
     - Changes 🔴 → 🟡 → 🟢
     - Checks off tasks
     - Documents findings
